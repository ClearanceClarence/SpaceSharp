Why people switch

A map you can move through, not a list you scroll.

Everything, sized to scale

The whole drive on one screen. A 16 GB page file and a forgotten 5 GB ISO stand out before you read a single name.

Zoom that goes all the way

Double-click a folder and the view flies in. The map is laid out again at every level, so tiny files get real pixels and sharp labels, up to a million times.

Filter in plain language

Type videos over 500MB older than 2 years. Everything else dims, the layout stays put, and one key selects every match.

Clean up from the map

Open, show in Explorer, or send to the Recycle Bin. Select many, delete once, and the map updates without a rescan. Nothing is deleted for good.

Honest numbers

File size or size on disk. Hard links counted once. Free space shown as a block. Protected folders flagged, with one click to restart as administrator.

Made to be looked at

Six map styles, eight palettes including a color-blind safe one, light and dark themes, and labels that stay readable on any color.

Questions

Things people ask.

Windows says "Windows protected your PC". Is it safe?

Yes. The warning appears because the download isn't code-signed, which costs a few hundred dollars a year. Click More info, then Run anyway. The full source is on GitHub, so you can see exactly what it does.

Does it send anything anywhere?

No telemetry, no accounts. Installed copies check GitHub for new releases on startup, which you can turn off in Settings. The portable version makes no network requests at all.

Will it delete anything by itself?

Never. It only deletes what you select and confirm, and only to the Recycle Bin, so everything can be restored.

Why does Windows look bigger than it should?

Windows stores thousands of files under several names (hard links). Turn on Count hard links once in Settings for exact numbers; it makes the scan a bit slower.

How is this different from WizTree or WinDirStat?

SpaceSharp is about the map: zooming, styles, filtering and cleaning up in place. WizTree is faster on very large drives because it reads the NTFS index directly. WinDirStat is the classic and hasn't changed much. Use whichever fits; they all read the same disk.

Is SpaceMonger involved?

No. SpaceSharp is an independent open-source project inspired by the original SpaceMonger's approach of drawing a drive as one map.
